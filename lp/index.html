事例イメージ

亡くなった叔父の相続人が、誰なのかわからない。

相続人調査戸籍収集遺産分割協議

状況

疎遠だった叔父が亡くなりました。親族に聞いても、誰が相続人なのか、誰も把握していません。

進め方

  1. 出生から死亡までの戸籍を、すべて集める
  2. 相続人を確定する（前の婚姻の子や、養子が見つかることもある）
  3. 相続人全員に連絡し、遺産分割協議へ
  4. 相続登記まで完了

ここが肝

相続人の調査は、戸籍をさかのぼっていく、根気のいる作業です。知らなかった相続人が出てくることも、めずらしくありません。

担当：司法書士（調査・登記）＋行政書士（書類）

事例イメージ

相続人が、一人もいない。

相続人不存在相続財産清算人特別縁故者

状況

独身の兄が亡くなりました。両親もきょうだいもすでに亡く、子もいません。自宅だけが残されたままです。

進め方

  1. 戸籍で、相続人がいないことを確認
  2. 家庭裁判所に、相続財産清算人の選任を申立て
  3. 清算人が財産を管理・清算
  4. 該当する場合は、特別縁故者への財産分与を申立て
  5. 残った財産は、国庫へ

ここが肝

そのままにすると、自宅は誰のものでもないまま残ってしまいます。家庭裁判所を通す手続きなので、専門家と一緒に進めましょう。

担当：司法書士（申立て・登記）

事例イメージ

相続人の一人が、30年前から行方不明。

所在調査不在者財産管理人

状況

兄弟姉妹の一人が、30年前から音信不通です。他の相続人は全員そろっているのに、手続きが止まっています。

進め方

  1. 戸籍の附票・住民票などで所在を調査
  2. 手紙で連絡を試みる
  3. 見つからない場合は、家庭裁判所に不在者財産管理人の選任を申立て
  4. 管理人が家庭裁判所の許可を得て、遺産分割協議に参加

ここが肝

一人でも欠けると、遺産分割協議は成立しません。まずは、居場所を探すところから始めましょう。

担当：司法書士（調査・申立て）

事例イメージ

祖父名義の土地が、3世代そのまま。

数次相続相続人申告登記期限対応

状況

祖父名義の土地が、そのままになっていました。祖父の後に父も亡くなり、相続人がきょうだいや叔父・叔母の家族へ広がっています。2024年より前の相続で、登記の期限は2027年3月31日です。

進め方

  1. 戸籍で、相続人全員を洗い出す
  2. 期限までに「相続人申告登記」で、まず義務を果たす
  3. その後、遺産分割協議を進め、相続登記へ

ここが肝

相続人申告登記は、「私は相続人です」と法務局に申し出る手続きです。期限が近くても、まず義務を果たす方法がありますから、大丈夫ですよ。

担当：司法書士（登記）

事例イメージ

きょうだいの一人が、認知症になっていた。

成年後見遺産分割相続登記

状況

母が亡くなり、相続人は長男・長女・次女の3人。長女は認知症で、判断する力が十分ではありません。

進め方

  1. 家庭裁判所に成年後見開始の申立て
  2. 選任された後見人が、長女の代わりに協議へ参加
  3. 遺産分割協議書を作成し、相続登記

ここが肝

判断する力が十分でない相続人は、自分では遺産分割協議に参加できません。その場合は、後見制度を使います。元気なうちに遺言や信託を準備しておけば、防げることもあります。

担当：司法書士（後見・登記）＋ケアマネ（介護の相談）
